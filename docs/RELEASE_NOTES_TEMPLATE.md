# DAYFORM v1.0.0

Initial Android release of DAYFORM, a personal task planner.

## Included

- Tasks, priorities, subtasks, categories, reminders and scheduled deadlines.
- Task search, calendar view and productivity insights.
- Preferences, onboarding and local JSON workspace backup/import.

## Installation

Download **DAYFORM-v1.0.0.apk** from this release's Assets section. Verify the SHA-256 hash against `SHA256SUMS.txt`, then install on Android 7.0 or later. To receive reminders, enable notification permission and grant exact-alarm access where your Android version requires it.

## Notes

Your tasks are stored locally on your device. Export a JSON backup before uninstalling, moving to another device, or experimenting with upgrade/signing changes.
