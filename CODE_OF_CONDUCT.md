# Code of Conduct

We expect respectful, constructive collaboration in issues, pull requests and other DAYFORM project spaces.

## Expected behavior

Be considerate and welcoming, assume good intent, focus on technical feedback, and help others learn. Disagreements are welcome; personal attacks, harassment, threats, discriminatory language, spam, or publishing private information are not.

## Reporting

Report conduct concerns privately to the repository maintainer through a private GitHub contact channel when available. For security issues, use [SECURITY.md](SECURITY.md). Do not share victims' personal information in public issues.

## Enforcement

Maintainers may hide or remove harmful content, close discussions, or restrict participation depending on severity. Reports will be evaluated fairly and handled with appropriate confidentiality.
